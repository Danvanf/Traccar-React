# Screenshot Guide

Use this folder for publishable product screenshots.

## Suggested capture set

1. Main map view with active trip/day selection.
2. Trip detail panel with event markers.
3. Settings modal (Named Places, Device Bindings).
4. Vehicle status cards.
5. Login screen (if auth enabled).

## Capture tips

- Use the same browser/window size for consistency.
- Avoid exposing private hostnames, emails, tokens, or IDs.
- Prefer sample/sanitized data before capture.
- Export PNG files for README/docs.

## Naming convention

- `01-map-overview.png`
- `02-trip-details.png`
- `03-settings-named-places.png`
- `04-vehicle-status-cards.png`
- `05-login-screen.png`

## Referencing in README

Example markdown:

```md
![Map overview](docs/screenshots/01-map-overview.png)
```
